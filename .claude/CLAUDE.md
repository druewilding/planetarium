# planetarium

An accurate, explorable sky in the browser: stand anywhere on Earth at any moment, or lift off above it. Plain HTML,
CSS and JS modules with **no build step**, served as-is on GitHub Pages and installable as an offline app. The README
describes every feature in detail; read the relevant part before changing one, and keep it in step (features, link
format, project structure, credits, roadmap ticks).

The goal behind it all: point a phone at the real sky and learn what's there. Accuracy to the eye on a phone comes
first.

## Working on it

- **Node comes from fnm:** run `eval "$(fnm env)"` before any `node`, `npm` or `npx`.
- **Never commit or branch.** Suggest a conventional commit message with a capitalised description instead.
- **Checks before calling anything done:** `npm test` (Vitest), `npm run lint:check`, `npm run format:check`. Look at
  the whole lint output, not just its last line.
- **ESLint and Prettier disagree about quotes.** ESLint wants double quotes and rejects template literals with nothing
  in them; Prettier turns a string full of `"` into single quotes. For HTML in strings, leave attributes unquoted
  (`<p class=note>`), use single quotes inside (`title='…'`), or `"`.
- **Every file the page loads goes in `APP_SHELL` in `sw.js`.** A test fails if one is missing.
- **Libraries come from a CDN** through the import map in `index.html`. `three` and `astronomy-engine` are exact dev
  dependencies too, for the tests; `npm run importmap` keeps the two in step.

## Tests

- Tests live in `test/` (singular), one file per module.
- `src/main.js` needs WebGL and a page, so it can't be tested. Put logic in small pure modules that it calls
  (`tonight.js`, `trail.js`, `deepsky.js`, `overviewZoom` in `ui/view.js`, `searchMatches` in `ui/panels.js`) and test
  those. New behaviour gets tests.
- Check against the real thing where you can: published eclipse and moon-event times, Horizons positions, guidebook
  answers (what's visible by eye).

## Looking at it

- Serve the folder (`npm run dev`, or any static server) and drive headless Chrome over the DevTools protocol
  (`--remote-debugging-port`), waiting for the sky to load. A one-shot `chrome --headless --screenshot` never finishes
  the network fetches.
- Check a desktop size (1280×800) and a phone (390×844), and watch for console errors. A shader that fails to compile
  only shows up there.
- GLSL has reserved words that JavaScript doesn't (`half`, `input`, `output`…).

## How the sky works

- **Frames:** the stars, constellations, Milky Way and deep-sky objects sit in J2000 equatorial coordinates inside
  `overlays.eqj`, which turns with the sky. The world frame is the horizon: y up, −z north, x east.
- **Real brightness:** everything is in cd/m² and lux, and the eye adapts (`exposure`). Whether anything faint shows
  comes from the sky's brightness right behind it: Schaefer's limiting magnitude for points, and surface contrast with
  Ricco's area for extended things (`deepsky.js`).
- **JavaScript and GLSL twins:** the same sums live in JS (for labels, picking, the info panel) and in shaders (for
  drawing): `airmass` and `limitingMag` in `deepsky.js` and `glsl.SEEING`, `seeing()` and `scene/deepsky.js`, the
  projection in `projection.js` and `glsl.PROJECTION`. Change both together.
- **Distances** go through `space.js`'s Sun-centred J2000 frame, never Earth-only shortcuts: standing on the Moon and
  other worlds is planned, and everything should work from any viewpoint.
- **Up above the Earth** (Lift off) the view is held still against the stars. The info panel still talks about the
  sky from your spot on the ground (`skyFromGround`).
- **Brave adds noise to pixels read through a canvas.** Never read data images that way: PNG tiles are decoded by
  hand (`png.js`).
- **Elevation tiles can't tell sea from land;** water comes from OpenFreeMap's map tiles instead.

## Data

- `data/` is generated by the scripts in `tools/` (each says how to run it at the top). `data/` is in
  `.prettierignore`: keep the files compact.
- `textures/milkyway.jpg` has the blurry glows of clusters and galaxies filled in (`tools/clean-milkyway.py`), since
  the deep-sky layer draws them. Re-run it if objects are added to `data/deepsky.json`.
- Place and mountain names come from the sister project `planetarium-labels` (static JSON squares). Don't add
  calls to Overpass.

## Words on screen

- Plain British English for anyone curious, not astronomers: explain a term the first time ("light-years", "Ricco's
  area"), or leave it out. Sentence case. Curly apostrophes (’) in visible text.
- Notes in the info panel link any planet, moon, constellation, named star or named deep-sky object they mention, by
  name (`linkMentions`), so write names out in full.
- Speeds of time are capped at ±12 hours a second.
