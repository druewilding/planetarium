## Decisions
- Use local Astronomy Engine calculations, Canvas 2D sky, and Three.js globe. Curated city zones use browser `Intl`; unidentified coordinates use labeled UTC. See `docs/adr/0001-model-and-render-static-earth-sky.md`.
- Use one latest globe sample, at least 50 ms apart during uninterrupted playback. Camera input and flight still repaint on animation frames. Paused edits and Now bypass the playback cadence; the simulated clock and model formulas are unchanged.
- Keep eager globe loading for this MVP. Bundle size is measured, but a cold-start timing gain from splitting is not established; changing bundle loading would add a request/failure path to Lift off and Place globe pin.
